ЯНДЕКС.ДИСК.БОКАП.ПАБЛИК — PUBLIC 1.1.7

Windows 10/11 x64, Windows PowerShell 5.1. Права администратора не нужны.

1. SELF-TEST.cmd — проверить комплект без подключения аккаунта.
2. START.cmd — открыть меню.
3. Пункт 1 — ввести ClientID СВОЕГО OAuth-приложения, открыть браузер и вставить токен только в скрытое поле ЭТОЙ консоли. ClientSecret не нужен. Инструкция: ../docs/OAUTH.md.
4. Пункт 2 — выбрать источник (/ = весь Диск) и локальную папку назначения.
5. Пункт 3 — подтвердить скачивание. Итог Verified=true подтверждает успешную проверку учтённых данных; 100% отдельного прохода этого не означает.

При ошибках после прохода будет вопрос ДА/НЕТ о повторе неподтверждённых файлов. Оригиналы не изменяются; отличающиеся локальные файлы не перезаписываются. Копирование можно продолжить через тот же пункт 3.

Настройки и токен создаются только после локального запуска, в %LOCALAPPDATA%\YandexDiskBackup-Public. Подключения других редакций не импортируются. Никому не отправляйте токены, rclone.conf и содержимое этой папки. Конфиг хранит токен открытым текстом под DACL, не в зашифрованном хранилище.

Отчёты в выбранном назначении содержат имена/пути файлов и сведения об аккаунте: не публикуйте их без очистки. Публичный проект не содержит готового аккаунта, токенов и личных файлов.

Это не атомарный снимок, не резервная копия корзины/версий/прав и не восстановление недоступных оригиналов. Для подробностей: ../README.md и ../SECURITY.md.
